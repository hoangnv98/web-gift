## Read first: this is Next.js 16, not the Next.js you know

Next 16.4 + React 19.3 have breaking changes in APIs, conventions and file structure. Before writing Next-specific code, read the relevant guide in `node_modules/next/dist/docs/` (run `pnpm install` first if `node_modules` is missing) and heed deprecation notices. `AGENTS.md` is auto-generated by `next dev`; commit it with your work rather than reverting it.

The project uses **Cache Components** (`cacheComponents: true` in `next.config.ts`), `"use cache"` + `cacheTag`/`cacheLife`, the two-argument `revalidateTag(tag, "max")`, and the global `LayoutProps<"/">` / `PageProps` type helpers.

## Commands

Package manager is **pnpm** (`packageManager: pnpm@12.9.1`).

```bash
pnpm dev          # http://localhost:3001 (port 3000 is reserved for the CMS)
pnpm build        # production build: needs the CMS reachable at CMS_URL
pnpm start        # serves the build on :3001
pnpm lint         # ESLint 9 flat config (next core-web-vitals + typescript)
pnpm typecheck    # tsc --noEmit
```

There is no test suite. Verify changes with `pnpm typecheck`, `pnpm lint` and by loading pages in `pnpm dev`.

Env vars go in `.env.local` (all `.env*` files are gitignored; the README's `.env.example` is not in the repo):
- `CMS_URL`: Payload admin base URL (default `http://localhost:3000`)
- `CMS_MEDIA_URL`: optional, Cloudflare R2 media host (added to `images.remotePatterns`)
- `NEXT_PUBLIC_SITE_URL`: canonical site URL (default `https://tqgift.vn`)
- `REVALIDATE_SECRET`: must match the value configured in the admin

## Architecture

This is the storefront for T&Q GIFT, a Vietnamese gift-box / corporate-gift catalogue. It has **no database and no static product data**. Every product, category, post, policy, menu, home-page config, B2B setting and SEO default comes from a separate repo, **tqgift-admin** (Payload CMS, `hoangnv98/tqgift-admin`), read over REST. The admin must be running for `dev` and `build`.

### Data flow

- `src/lib/cms.ts` is the only CMS read layer. `cmsFetch`/`cmsList` call `{CMS_URL}/api/<collection>`, and mapper functions convert Payload docs into flat storefront types (`Product`, `Category`, `Settings`, `ImageRef`…). Components consume these mapped types, never raw Payload types.
- Every getter is `"use cache"` with a `cacheTag` (`products`, `categories`, `materials`, `tags`, `posts`, `policies`, `settings` plus `navigation`/`home`/`b2b`/`seo`) and `cacheLife("weeks")`, so pages prerender statically. `getProduct(slug)`/`getPost(slug)` filter the cached full list rather than fetching individually.
- Freshness: the admin calls `POST /api/revalidate` (`src/app/api/revalidate/route.ts`) with header `x-revalidate-secret` and body `{ "tags": [...] }`. **If you add a getter, give it a tag the admin actually sends.**
- `src/lib/payload-types.ts` is **copied from the admin** (`pnpm generate:types` there). Don't hand-edit it; re-copy it when the CMS schema changes, then update the mappers in `cms.ts`.
- `toImage()` turns Payload `Media` into `ImageRef` with `src`/`card`/`thumb` sizes and makes relative `/api/media/...` URLs absolute against `CMS_URL`. `next.config.ts` derives `images.remotePatterns` from `CMS_URL`/`CMS_MEDIA_URL`, and sets `dangerouslyAllowLocalIP` only when the CMS is on localhost.
- Writes: the quote form (`src/components/b2b/quote-form.tsx`) uses the Server Action `src/app/actions/quote.ts`, which maps Vietnamese form labels to CMS enum values and POSTs to `{CMS_URL}/api/quote-requests`. It includes a `website` honeypot field.

### Sources of truth that live in code, not the CMS

- `src/lib/company.ts` (`COMPANY`): the legal entity name, tax code, address, hotline, Zalo, bank, Maps embed and review link. These must appear verbatim. `getSettings()` deliberately overrides CMS values with these for legal fields.
- `src/app/layout.tsx`: LocalBusiness JSON-LD and the Microsoft Clarity snippet are hard-coded here. GA4 is injected only when the CMS SEO settings provide `ga4Id`.
- `src/lib/reviews.ts`: suggested review texts for `/danh-gia`.
- `src/lib/images.ts`: fixed editorial images (Unsplash) for About/hero sections.

### Client vs server

Pages under `src/app/**` are async Server Components that fetch through `cms.ts` and pass plain data down. Interactivity lives in `"use client"` components:
- `src/lib/store.ts` holds cart, wishlist and the 18+ age-gate flag in localStorage (`tqgift-store-v1`) via `useSyncExternalStore`. There's no server-side cart.
- `catalogue-view.tsx` keeps filter state (occasion/group, material, price tier, sort) **in the URL** via `useSearchParams` + `router`, so it must stay wrapped in `<Suspense>` (see `src/app/catalogue/page.tsx`). The pure filter, sort and label logic is in `src/lib/catalogue.ts`.
- The root layout passes `products.map(toLite)` to `Header` for instant client-side search. Keep `ProductLite` small, because it ships on every page.
- Products whose tags have `ageGate` (wine) trigger `layout/age-gate.tsx`.
- The header nav is not rendered 1:1 from the CMS. `arrangeMainNav()` in `src/lib/product-menu.ts` folds the `/qua-tet`, `/qua-doanh-nghiep` and `/qua-trung-thu` links into a single "Sản phẩm" mega menu and adds "Hồ sơ năng lực" after "Giới thiệu". `buildProductMenu()` builds that mega menu on the server (in `layout.tsx`) from the CMS `megaMenu` columns plus fixed groups (B2B, budget tiers, materials). Its tile images come from category images or the first matching product.
- `/ho-so-nang-luc` (capability profile for B2B/FDI buyers) only shows real data. The PDF download appears once `COMPANY.capabilityProfilePdf` is set. Client logos appear only when the CMS partner logos have uploaded images.

### Styling

Tailwind CSS v4 through `@tailwindcss/turbopack` (configured in `next.config.ts` `turbopack.rules`; there is no `tailwind.config`). Design tokens live in the `@theme` block of `src/app/globals.css`: the `navy`, `gold`, `ruby`, `sun`, `tet`, `ink` palettes. The whole site uses one font, **Be Vietnam Pro** (loaded in `layout.tsx` as `--font-body`), matching mincygroup.com. The `font-display`, `font-cat-sans` and `font-cat-serif` tokens all point to it, and headings use light or normal weights. Use `cn()` from `src/lib/utils.ts` (clsx + tailwind-merge) to merge classes.

Brand assets: the horizontal logos (gold for dark backgrounds, maroon and white variants) are in `src/assets/brand/` and rendered by `Logo` in `src/components/ui/logo.tsx`. The favicons are `src/app/icon.png` and `apple-icon.png`. `public/logo.png` is the logo URL used in the JSON-LD.

## Conventions

- All user-facing copy, route slugs (`/qua-tet`, `/gio-hang`, `/chinh-sach/[slug]`…), code comments, README and commit messages are in **Vietnamese**. Follow that.
- Prices are VND integers formatted with `formatVnd()`. Catalogue copy states that prices exclude VAT.
- Path alias `@/*` → `src/*`.
